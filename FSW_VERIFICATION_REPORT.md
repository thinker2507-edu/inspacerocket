## C. System overview and trace paths

Rocket `finalfsw/` uses Teensy4.1, BMP581/BNO085 on Wire2 SDA25/SCL24, DS3231 Wire SDA18/SCL19, INA219 Wire1 SDA17/SCL16, GNSS Serial7 RX28/TX29. SX1262 uses SPI11/12/13, NSS2/RESET6/BUSY4/RXEN1/TXEN0. W25Q64JV recovery NOR shares SPI with independent CS10. Routine samples use onboard SDIO CSV. Rocket alone has RunCam Serial5 TX20/RX21/115200 and Servo.h pins22/23. Independent CanSat23:C has no camera/servo; PSMS is a placeholder.

Sensors → validity/calibration → pad-relative pressure altitude/gravity-projected complementary estimate → sustained flight-state decisions → snapshots/logs/telemetry. `buildPacket()` has16 CSV fields: index3 fresh barometric relative altitude (invalid becomes `nan`),4 pressure Pa,12 raw acceleration m/s2,13 gyro deg/s,14 state0..5,15 optional source/epoch. Packet timestamp is boot millis; it is distinct from launch-only onboard mission time.

GCS command → addressed key/XOR/sequence envelope → ESP32 bridge → common dispatcher → same-origin ACK. Main SEDS BPHC GCS plots both identities but commands23:R only; CanSat GCS commands23:C. Counters/epochs and journals remain independent. Main GCS displayed mission time intentionally starts at first accepted telemetry, not launch; onboard MissionClock starts only at detected launch and restores time or flags uncertainty.

Fresh PAD routine telemetry and unsolicited SYS start OFF; STATUS/command RX/ACK remain available. After first ON, ordinary OFF leaves SYS/ACK alive. Existing launch/in-flight recovery forces ON. MAIN865.50/BACKUP867.25 MHz retain SF7, BW125kHz, CR4/5, sync0x95,14dBm. Manual backup is not a simultaneous separate-channel reception solution.

Mass is grams, CP/CG/reference length centimetres, density g/cm3. Reference area is not assumed to be one-fin area; reference length is not overall rocket length.
